# Thmanyah Sans Fonts

Please place the following font files in this folder (`/public/fonts/`):
- `thmanyahsans-Regular.otf` (Regular weight)
- `thmanyahsans-Medium.otf` (Medium weight)
- `thmanyahsans-Bold.otf` (Bold weight)
- `thmanyahsans-Light.otf` (Light weight)
- `thmanyahsans-Black.otf` (Black weight)

After placing them here, the website will automatically load and use the "Thmanyah Sans" font as its primary typeface!
